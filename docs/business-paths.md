# 业务路径总览

平台只有一条主干:**数据归集 → 指标与算法 → 发布管理 → 发布后响应**,驾驶舱(全息图)位于主干之上,把四个环节的状态汇成一屏;机构、县区、省级、监督席位分别从各自入口接收发布成果并反馈。菜单分组与此一一对应。

```
                         ┌────────────── 驾驶舱 · 全息图(核心展示) ──────────────┐
                         │  钱·效·错 气泡全景 / 区域外流向 / 公开状态矩阵 / 关键病组巡航  │
                         └──────────────────────────────────────────────────────┘
 数据归集 ──▶ 指标与算法 ──▶ 发布管理 ──▶ 发布后响应
 (数据底座)   (第二层核心)    (唯一出口)     (闭环回流)
```

## 一、主干路径

| 环节 | 页面(菜单分组) | 做什么 | 上游 → 下游 |
|---|---|---|---|
| 数据归集 | 数据归集中心(数据底座) | 十类数据源到数、标准化、主数据对齐、质量校验 | 数据源 → 校验完成才允许生成月度报告与出指标 |
| 指标与算法 | 指标配置 · 算法沙盘 · 智能推荐中心 · 病组专题工作台 · 图表与报告模板 | 定义指标、试算口径与小样本抑制、算法推荐专题、七段式专题、拼装报告 | 校验完成的数据 → 上线审批单 / 报告草稿 / 专题稿 |
| 发布管理 | 发布工作流 · 展示策略配置 · 流程设计器 | 十步工作流、整包审批、对标三档、四象限策略、流程模板 | 草稿与审批单 → 召集人批准 → 定向发布 |
| 发布后响应 | 意见管理 · 预警与整改 | 机构意见答复、预警提醒函、回执、整改销号 | 机构反馈 → 回写发布流程(未答复不得归档) |

唯一通道:**分析监测区的数据只能经发布工作流第 5 步(召集人审批)进入发布区**。

## 二、五条端到端路径

1. **月度发布**:数据归集(到数 + 质量校验)→ 图表与报告模板(生成草稿)→ 发布工作流(分析成稿 → 专家审核 → 召集人审批 → 定向发布 → 签收查阅 → 意见申诉 → 答复整改 → 归档)→ 机构报告中心签收。
2. **指标上线**:指标配置(向导 / 算法沙盘试算阈值)→ 提交上线审批 → 发布工作流批准(申请人与审批人不得为同一人)→ 指标已上线并登记对标档位。
3. **对标档位切换**:展示策略配置发起(理由必填)→ 发布工作流召集人批准 → 机构端同级对标按新档位呈现(审批前按匿名分位)。
4. **预警闭环**:智能推荐中心识别异常 → 生成提醒函草稿 → 预警与整改触发记录(待发出)→ 发出 → 机构意见与核对页回执 → 整改跟踪 → 销号。
5. **导出**:任一可导出页面申请 → 我的导出(待审批,召集人审批他人 / 行政管理组审批召集人)→ 批准 → 带实名水印下载(有效期、次数)→ 全程审计。

## 三、角色入口

| 角色 | 首页 | 主要路径 |
|---|---|---|
| 召集人 | 全息图驾驶舱 | 审批(发布、指标、档位)、导出审批 |
| 行政管理组 | 全息图驾驶舱 | 归集、指标配置、报告、提交审批、意见与预警处置 |
| 意见承办人 | 意见管理 | 答复机构意见 |
| 委托分析团队 / 专家组 | 病组专题工作台 | 受控环境内分析与审阅,导出须审批 |
| 安全管理员 / 审计员 | 用户权限 / 审计日志 | 三员分立,互不可见业务数据 |
| 医疗机构 | 本院全息图 | 签收报告、核对与意见、预警回执 |
| 县区 / 省级 / 外部监督 | 各自视图 | 只读汇总,监督席位限时失效 |

## 四、两层核心

- **第一层 · 驾驶舱(数据发布的核心展示)**:一屏呈现钱、效、错、区域外、公开状态,支持关键少数病组巡航、大屏模式与实时播报。
- **第二层 · 指标可视化设计与算法模拟**:指标配置的向导(公式校验、机构身份预览)与算法沙盘(拖动抑制阈值,由分析引擎即时试算同级分布、抑制判定与超 P75 机构),智能推荐的方法卡可追溯。
