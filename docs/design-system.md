# 设计系统:「数据期刊」

定位:政务数据发布平台应当像一本可信的数据期刊——克制、权威、信息密度高,而不是通用的 SaaS 仪表盘。

| 要素 | 规则 |
|---|---|
| 色彩 | 宣纸底 `#F3EFE4`、墨 `#16130F`(文字与重线)、靛青 `#28458F`(主色、链接、选中)、朱砂 `#B8321F / #C2371F`(逆差、预警、印章与强调)、琥珀(关注)、松绿(结余、正常);深色为暖黑 `#0F0E0C`。全部以令牌写在 `web/src/style.css`,组件不写十六进制 |
| 字体 | 标题、数字、导轨阶段名用宋体系 `font-display`(Noto Serif SC / Songti SC);正文用无衬线 Inter + 苹方 / 微软雅黑;数字一律 `tabular-nums` |
| 形状 | 直角为主(圆角 2–4px);1px 墨线框 + 浅色分隔,不使用阴影与玻璃拟态(驾驶舱大屏除外) |
| 页头 | 朱砂小标题(阶段名,字距 .24em)+ 宋体大标题 + 说明 + 墨色双线 |
| KPI 卡 | 顶部 3px 语义色条,宋体大数字,虚线分隔的说明行 + 迷你柱 / 折线(仅在有真实序列时) |
| 导轨 | 四个业务阶段编号 01–04 并以竖线串联;驾驶舱、系统管理、导出等为非阶段分组;选中项朱砂菱形标记 |
| 业务路径看板 | 驾驶舱顶部一行呈现 01 数据底座 → 04 发布后响应的进展与待办,点击进入对应页面 |
| 驾驶舱 | 暖黑底 + 朱砂 / 琥珀光晕 + 细网格 + 扫描线;数字滚动、气泡弹出、脉冲光环、流向线流动、关键病组巡航、大屏模式 |
| 登录页 | 左侧墨色刊头(朱砂印章、宋体大标题、编号要点),右侧纸色认证卡片,朱砂顶线 |
