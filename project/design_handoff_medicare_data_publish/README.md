# Handoff:医保数据公开定向发布平台

## Overview
面向统筹地区医保局“医保数据工作组”的 B 端平台,按月/季/年向辖区定点医疗机构定向发布医保数据。产品主线为五环节闭环:**多源归集 → 指标配置 → 智能推荐 → 审批发布 → 全息展示**。平台分两个区:

- **分析监测区**:医保局内部,可至病例级。
- **发布区**:面向机构与外部,仅经审批的聚合结果。

数据从分析监测区进入发布区的**唯一通道是发布工作流**(第 5 步召集人审批)。完整业务需求见 `原始需求.md`。

## About the Design Files
本包中的 `.dc.html` 是**用 HTML 制作的设计参考原型**,用于展示目标外观与交互,**不是可直接上线的生产代码**。任务是在目标代码库的现有技术栈(React / Vue 等)中按其既有模式与组件库**重新实现**这些设计;若尚无代码库,请选用适合政务 B 端的框架(建议 React + TypeScript + 企业级组件库)实现。

- 双击任一 `.dc.html` 可在浏览器中直接打开(依赖同目录 `support.js`)。
- 页面可通过 URL hash 直达,例如 `医保数据公开平台 第一批.dc.html#A8`。
- 每个文件内:模板为 `<x-dc>` 内的 HTML(全部内联样式);逻辑为 `<script data-dc-script>` 中的 `class Component`,`renderVals()` 计算模板所需数据;所有样例数据为文件顶部常量。
- 每页顶部有“设计说明”条(页面目标 / 关键交互),为原型注释,**生产环境不需要**。左侧“原型导航”同理,生产中应替换为按角色裁剪的真实菜单。

## Fidelity
**高保真(hifi)**。颜色、字号、间距、圆角、状态色均为最终值,请按像素还原;图表需用实际图表库重绘,但须保留编码规则(见下文“图表规范”)。样例数据全部虚构。

## 三条贯穿规则

1. **对标三档**(每个指标可配):`匿名分位`(默认)/ `匿名编号`(“三级医院A”)/ `具名PK与排行`。切换需召集人审批,审批通过前按原档位发布。
2. **区域内外差异化**(A13 四象限):
   - 区域内 × 区域内:最细,至病组与诊疗行为。
   - 区域内 × 区域外:按地区、等级、病种汇总;就医地机构排名仅医保局可见。
   - 区域外 × 区域内:仅汇总与经授权对标值。
   - 区域外 × 区域外:不提供。
3. **仅内部**:个人级、病例级指标标记“仅内部”,列表中整行 opacity 0.55 置灰,“加入发布包”禁用(`not-allowed`),发布包自动排除。

小样本抑制:同级机构 < 5 家或病例 < 30 例,不输出同级分位;机构端病组病例 < 30 显示“已并入其他”。
